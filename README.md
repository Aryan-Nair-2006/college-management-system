# College Life Management System
A college life management system with personal information, attendance tracking, event registration, and grade calculation using HTML, CSS, and JavaScript

## Features
- Personal Information display
- Attendance Tracking with Canvas for Visualization
- Event registration and deletion
- Grade Point Average (GPA/CGPA) calculation from preset values
- Proper Navigation between pages
- Clean and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository
2. Open homepage.html in any browser
